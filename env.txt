import os

name = os.getenv("MY_NAME", "World")
print(f"Hello {name} from Python")

if you run this code it will return "Hello World from Python"

instead if you provide through terminal that 
export MY_NAME="Wade Wilson"

then it will return "Hello Wade Wilson from Python"
